# 🧠 AI Sentiment Analysis System

An AI-powered web app that analyzes the sentiment of any text as Positive, Negative, or Neutral.

## 🔧 Built With
- Python
- TextBlob (NLP)
- Gradio (Web Interface)

## 🚀 How to Run
1. Clone this repo
2. Run `pip install textblob gradio`
3. Run `python -m textblob.download_corpora`
4. Run `python app.py`
5. Open http://127.0.0.1:7860 in your browser

## 📌 Features
- Real-time sentiment detection
- Polarity and subjectivity scores
- Clean web interface with example inputs
